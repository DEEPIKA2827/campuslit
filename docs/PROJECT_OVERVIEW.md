# Project Overview: CampusLit

## Executive Summary

**CampusLit** is a dedicated student operating system and digital workspace built for first-year engineering students across VTU-affiliated and autonomous colleges in Karnataka.

Modern engineering education in Karnataka suffers from extreme information fragmentation. Students rely on over 40 unorganized WhatsApp and Telegram chat groups, lost PDFs, and word-of-mouth senior advice. CampusLit replaces this chaos with a unified, zero-noise dashboard that aggregates syllabus modules, predictive CIE and attendance calculators, verified senior playbooks, and day-one career skill roadmaps.

---

## Core Value Proposition

1. **Zero Information Clutter**: Consolidates 50+ WhatsApp group forwards into clean, searchable cards organized by subject and semester.
2. **Predictive 75% Attendance Defense**: Live calculation of safe bunk allowances and alert warnings before official college detention lists are posted.
3. **CIE Target Calculator**: Precise mathematical breakdown of marks needed in IA1, IA2, IA3, and Lab CIE to achieve target SGPAs (e.g., 8.5+ Distinction).
4. **Vetted Senior Playbooks**: Lab viva question banks, repeat PYQ derivations, and professor expectations curated by top 3rd/4th-year students.
5. **Day 1 Technical Advantage**: Structured technical roadmaps guiding first-years from Git/Linux basics to LeetCode starter sets and hackathon proof-of-work.

---

## Current Release Scope: Version 0.1.0 (Design Prototype)

The current release represents **v0.1.0 (Design Prototype)**, establishing the core user interface, design system, interactive simulators, and route structure:

* **Landing Page (`/`)**: Main showcase with interactive OS window demo, live attendance/CIE risk simulator, WhatsApp chaos comparison matrix, and waitlist form.
* **Onboarding Flow (`/onboarding`)**: 4-step wizard for institution, branch, grading scheme, and target setup.
* **AI Mentor UI (`/ai-mentor`)**: Conversational interface prototype for VTU scheme queries.
* **Scholarships Finder (`/scholarships`)**: Searchable directory for Karnataka SSP/NSP scholarships.
* **Opportunities Radar (`/opportunities`)**: Hackathon, club event, and internship aggregator.
* **Skill Roadmap (`/roadmap`)**: Semester-by-semester technical career progression.

---

## Target Audience & Geographic Scope

* **Primary Users**: 1st-Year Engineering Students (Physics Cycle & Chemistry Cycle).
* **Target Region**: Karnataka, India.
* **Institutions Supported**:
  * **VTU Affiliated Colleges**: Following VTU 2022 and 2025 scheme grading structures.
  * **Autonomous Institutions**: Top autonomous campuses including RVCE, BMSCE, PES University, MS Ramaiah (MSRIT), NMIT, NIE Mysore, SIT Tumakuru, and KLS GIT Belagavi.

---

## Stakeholder Goals & Success Metrics

* **Student Experience**: Reduce academic anxiety, eliminate attendance detention surprises, and boost average 1st-year SGPAs above 8.0.
* **System Performance**: Sub-second page loads, 60 FPS glassmorphic animations, and 100% mobile accessibility.
* **Open Source Standards**: Clean TypeScript interfaces, reusable component modularity, comprehensive documentation, and zero build warnings.
