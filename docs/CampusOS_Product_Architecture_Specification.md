# 🧭 CampusLit — OS Brand Nomenclature & Product Architecture

**Role:** Senior Product Manager  
**Product:** CampusLit — *The Operating System for Karnataka Engineering Students*  
**Brand Philosophy:** **Operating System Nomenclature** (Mission-Oriented, High-Signal, Zero SaaS Generic Terms)  

---

## 1. Unified OS Brand Nomenclature

We replace generic SaaS page titles (`"Dashboard"`, `"Resources"`, `"Profile"`) with high-leverage Operating System vocabulary that reinforces the student's identity as a high-velocity engineer.

| Old Generic Name | New OS Brand Name | Visual Symbol | Core Job-to-be-Done |
| :--- | :--- | :---: | :--- |
| **Dashboard** | **Mission Control** | 🏠 | Daily single-focus mission execution & 75% attendance radar. |
| **Roadmaps** | **Navigator** | 🧭 | Visual node-by-node semester milestone pathing from Sem 1 to Graduation. |
| **Opportunities** | **Opportunity Radar** | 🎯 | Hackathons, competitive coding, tech fellowships, & campus drives. |
| **Resources** | **Knowledge Vault** | 🎓 | Verified VTU & Autonomous module summaries, PYQs, & lab viva playbooks. |
| **Scholarships** | **Grant Radar** | 💰 | Karnataka SSP, NSP, Jindal Trust & Corporate grant tracking. |
| **Projects** | **Skill Tree** | 🏆 | Proof-of-work project showcase & GitHub commit streak tracking. |
| **AI Mentor** | **AI Senior Copilot** | 🤖 | 24/7 instant VTU derivation solver, C debugger, & viva practice. |
| **Community** | **Campus Network** | 👥 | IEEE/GDSC tech club integration & hackathon teammate matchmaker. |
| **Profile** | **Command Profile** | 👤 | Public digital engineering passport, verified skill badges, & resume pass. |


## 3. End-to-End User Flow (Student OS Lifecycle)

```
[1. Freshers Onboarding] 
   Student signs in via Google ──► 60s Setup (College, Branch, Semester, Evaluation Scheme, & Career Goal).
        │
        ▼
[2. Morning Action (Mission Control)] 
   Opens Mission Control at 8 AM ──► Sees single high-dopamine "Today's Mission" (e.g. Complete Git Basics, 25 mins).
        │
        ▼
[3. Academic Execution (Knowledge Vault & Navigator)] 
   Navigates to Knowledge Vault & Navigator ──► Downloads VTU module summaries, prepares for lab vivas, & tracks 75% attendance.
        │
        ▼
[4. Portfolio Building (Skill Tree & Opportunity Radar)] 
   Uses Skill Tree & Opportunity Radar ──► Joins a 48h hackathon, builds proof-of-work, & earns verified skill badges.
        │
        ▼
[5. Career Placement (Placement Launchpad & Command Profile)] 
   Uses Placement Launchpad ──► Practices company interview questions & generates shareable Command Profile for campus drives.
```
